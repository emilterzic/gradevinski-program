# Građevinski program – koncept v0.1 (10. 11. 2026.)

Cijeli dokument: https://claude.ai/artifact/Vs3QyxJKxWa5W39qSin5zV

## Smjer
- Jedna jezgra za cijelu EU + državni paketi (Hrvatska prva; zatim Slovenija, Austrija ili Njemačka).
- Korisnik vidi 4 koraka: učitaj projekt (IFC/PDF/DWG) → izmjere (AI predlaže, čovjek potvrđuje ili upisuje ručno)
  → cijene po stavci → troškovnik i ugovor jednim klikom.
- Osnovna jedinica je stavka: element / izmjera → stavka → faza gradnje (iskop do fasade).
- Korisnici: projektant i izvođač.
- Propisi: GDPR, EU AI Act (transparentnost; bez praćenja radnika), Data Act (izvoz podataka),
  CRA (ako bude instalirana aplikacija), Fiskalizacija 2.0 (eRačun UBL 2.1).
- Formati po državama: HR bez državnog formata troškovnika; DE GAEB DA XML / STLB-Bau; AT ÖNORM A 2063 / LB-HB.
- 3D/BIM: IFC kao osnova, prijedlog That Open Engine (MIT) za preglednik.

## Faze
0 Temelj → 1 MVP Hrvatska → 2 AI izmjera → 3 druga država → 4 gradilište/mobitel.
